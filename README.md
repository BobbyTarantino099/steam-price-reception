# On Steam, the cheapest price band has the worst reception across all 10 genres

> Games priced under a real $3.25 systematically get the worst reception in their genre. The
> best reception sits at $6.46-$12.36 — never the cheapest, and not always the most expensive
> either.

`Python` `pandas` `matplotlib` `125,855 games` `2 sources combined`

**Full case, findings and recommendations →
[juanesportfolio.com/cases/steam-price-reception](https://juanesportfolio.com/cases/steam-price-reception/)**

## Data

| Source | Period | Volume | Licence |
|---|---|---|---|
| [Steam Games Dataset](https://www.kaggle.com/datasets/fronkongames/steam-games-dataset) (fronkongames) | 1997-06-30 → 2026-05 | 125,855 games × 40 columns | CC BY 4.0 |
| [CPI-U, series `CUUR0000SA0`](https://www.bls.gov/cpi/) (US Bureau of Labor Statistics) | 1997-2026 | Annual index | Public domain |

The raw Steam CSV is ~400 MB and is **not stored in this repository** — download it from the
Kaggle link (see Reproduce). Attribution required by CC BY 4.0: fronkongames dataset, Kaggle. No
PII in either source.

## Reproduce

```bash
# 1. Clone
git clone https://github.com/BobbyTarantino099/steam-price-reception.git
cd steam-price-reception

# 2. Dependencies
pip install pandas matplotlib seaborn python-docx
npm install --prefix notebooks pptxgenjs

# 3. Download the raw file (not in the repo, ~400 MB)
#    https://www.kaggle.com/datasets/fronkongames/steam-games-dataset
#    Save it as:
#    datos/crudos/steam_fronkongames_catalogo-historico_2026-07-28.csv
#    The CPI-U file is already at datos/crudos/bls_cpi-u_anual_1997-2026_2026-07-28.csv

# 4. Run in order
python notebooks/procesar.py    # cleaning -> datos/limpios/
python notebooks/analizar.py    # quartiles and genre x band table -> salidas/tablas/
python notebooks/verificar.py   # the 7 analysis checks
python notebooks/graficos.py    # the 4 figures -> salidas/graficos/
```

The end-to-end narrated notebook is at
[`notebooks/caso_steam_precio_recepcion.ipynb`](notebooks/caso_steam_precio_recepcion.ipynb).
